# Data_Analysis_Dashboard
An interactive Employee Attrition Analysis Dashboard developed using Microsoft Excel to analyze employee turnover and identify key factors associated with attrition. The project uses data cleaning, Excel formulas, Pivot Tables, Pivot Charts, KPIs, and interactive slicers to provide HR-focused insights.
## Key_Features
Data cleaning and preparation
Advanced Excel formulas and functions
KPI calculation: Total Employees, Employees Left, Employees Stayed, Attrition Rate
Pivot Tables and Pivot Charts
Attrition analysis by Department and Job Role
Overtime and Job Satisfaction analysis
Age-group analysis
Interactive slicers for dynamic filtering
Professional HR dashboard design
