# Data_Analysis_Dashboard
An interactive Employee Attrition Analysis Dashboard developed using Microsoft Excel to analyze employee turnover and identify key factors associated with attrition. The project uses data cleaning, Excel formulas, Pivot Tables, Pivot Charts, KPIs, and interactive slicers to provide HR-focused insights.
## Key_Features
Data cleaning and preparation
Advanced Excel formulas and functions
KPI calculation: Total Employees, Employees Left, Employees Stayed, Attrition Rate
Pivot Tables and Pivot Charts
Attrition analysis by Department and Job Role
Overtime and Job Satisfaction analysis
Age-group analysis
Interactive slicers for dynamic filtering
Professional HR dashboard design

## Project Process
1. Data Collection
I started with an employee dataset containing employee demographics, job information, salary, satisfaction, overtime, experience, and attrition details.
2. Data Cleaning
I checked the dataset for missing values, duplicate records, incorrect data types, and unnecessary columns, and prepared the data for analysis.
3. Data Preparation
I converted the dataset into an Excel Table and organized the columns. I also created calculated fields such as Age Group where required.
## Insights & Recommendations
I analyzed the dashboard to identify departments and job roles with relatively higher attrition and examined factors such as overtime, job satisfaction, and employee demographics that could help HR understand turnover patterns.
## Overview
First, I collected and cleaned the employee dataset. Then I prepared the data in Excel and created calculated fields where required. I calculated important KPIs such as total employees, employees left, employees stayed, and attrition rate. After that, I performed analysis using Advanced Excel formulas and Pivot Tables. I converted the analysis into Pivot Charts and created an interactive dashboard using KPI cards and slicers. Finally, I analyzed the dashboard to identify employee attrition patterns across departments, job roles, overtime, age groups, and other HR factors.
